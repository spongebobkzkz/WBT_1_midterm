# Cargo/Pulse

A front-end website for a cargo delivery service in Kazakhstan and Central Asia.
Web Technologies 1, Endterm project.

Website: https://spongebobkzkz.github.io/WBT_1_midterm/

## What a visitor can do

- Home: read the questions (accordion) and see the numbers count up.
- Services: open the details of a service and compare up to 3 services.
- Tracking: find a shipment by its code and see its journey; filter the table by status.
- Get a quote: see the price for air, rail and road while typing and send a checked request.
- Pickup: choose a courier time window, see the price and book a pickup.
- Packing shop: search and sort supplies, use the cart and find the right box size.
